# Tech Entrepreneur Identity Training System

Static React/Vite MVP designed for GitHub Pages. No auth, backend, database, or API key required.

## Run
npm install
npm run dev

## Build
npm run build

The Vite config uses a relative base (`./`) for GitHub Pages compatibility.

## Publish
Push the repository to GitHub, then use GitHub Pages with GitHub Actions or deploy the `dist` output through your preferred Pages workflow.
